Drop your voice recordings here with these exact filenames.
If a file is missing, the app automatically falls back to
the browser's built-in speech synthesis, so nothing breaks.

  intro.mp3          - "Hey [name]... I found something that belongs to you..."
  level1.mp3         - map narration
  level2.mp3         - room narration
  level3.mp3         - cave narration
  almost-there.mp3   - path narration
  final.mp3          - final reveal / personal message
  ambient.mp3        - optional quiet looping background music/ambiance
  chime.mp3          - optional short reveal chime (currently synthesized)
  whoosh.mp3         - optional transition whoosh (currently synthesized)

Any mp3 works. Keep them short and intimate — a phone voice memo is perfect.
